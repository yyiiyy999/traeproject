#### 3. NOTICE技能实现

**技能匹配**
```python
skill_to_call = None
for skill in skills:
    skill_name = skill['name']
    if skill_name == "notice":
        notice_keywords = ["通知", "放假", "公告", "撰写通知", "修改通知", "润色通知"]
        if any(keyword in text_lower for keyword in notice_keywords):
            skill_to_call = skill_name
            break
```
