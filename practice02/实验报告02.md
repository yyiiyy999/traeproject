## 实验内容

### 实验过程

#### 1. 代码结构分析

本实验包含两个Python文件：

**chat_client.py** - 文件操作工具客户端
- `list_files()`: 列出目录下的文件及其属性
- `format_size()`: 文件大小格式转换
- `rename_file()`: 重命名文件
- `delete_file()`: 删除文件

**tool_chat_client.py** - 网络访问工具客户端
- `fetch_webpage()`: 通过curl获取网页内容
- `get_current_date()`: 获取当前日期时间

#### 2. 工具调用机制

**工具定义**
```python
TOOL_FUNCTIONS = {
    'list_files': list_files,
    'rename_file': rename_file,
    'delete_file': delete_file,
    'create_file': create_file,
    'read_file': read_file
}
```

**工具调用流程**
1. 用户输入消息
2. LLM分析是否需要调用工具
3. LLM输出JSON格式的工具调用指令
4. 解析工具调用并执行对应函数
5. 将工具执行结果返回给LLM
6. LLM生成最终总结回答

**系统提示词设计**
```python
SYSTEM_PROMPT = """
你是一个文件操作助手，你可以执行以下文件操作：
可用工具：
1. list_files(directory) - 列出指定目录下的所有文件
2. rename_file(directory, old_name, new_name) - 重命名文件
3. delete_file(directory, filename) - 删除文件
4. create_file(directory, filename, content) - 创建文件
5. read_file(directory, filename) - 读取文件内容

格式要求：
- 当你需要调用工具时，请输出JSON格式：{"tool": "工具名称", "args": {"参数名": "参数值"}}
"""
```

#### 3. 核心技术实现

**工具调用解析**
```python
def parse_tool_call(response):
    try:
        response = response.strip()
        if response.startswith('{') and response.endswith('}'):
            data = json.loads(response)
            if 'tool' in data and 'args' in data:
                return {'tool': data['tool'], 'args': data['args']}
        return None
    except json.JSONDecodeError:
        return None
```

**工具执行**
```python
def execute_tool(tool_name, args):
    if tool_name not in TOOL_FUNCTIONS:
        return {'success': False, 'error': f"未知工具: {tool_name}"}
    func = TOOL_FUNCTIONS[tool_name]
    try:
        return func(**args)
    except Exception as e:
        return {'success': False, 'error': str(e)}
```

## 实验总结

### 实验成果

1. 成功实现了文件操作工具集，支持列出目录、创建、读取、重命名、删除文件
2. 实现了网络访问工具，支持网页获取和天气预报查询
3. 建立了完整的工具调用流程：解析→执行→总结
4. 实现了JSON格式的工具调用指令解析机制

### 技术要点

1. **工具注册机制**: 通过字典映射工具名称和函数，便于扩展
2. **指令格式约定**: 使用JSON格式传递工具调用指令，便于解析
3. **错误处理**: 完善的错误处理机制，捕获网络异常和参数错误
4. **两阶段响应**: 先调用工具获取数据，再生成总结回答
